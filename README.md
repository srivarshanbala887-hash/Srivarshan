# CampusAI – AI-Based College Event Management System

> **“One Campus. Every Event. Smarter with AI.”**

CampusAI is a modern, responsive college event management web application built with **React**, **Vite**, and **Tailwind CSS**. It provides a centralized hub for students and university administrators to discover, register, create, track, and manage collegiate events with simulated AI recommendation, popularity prediction, and digital QR ticketing.

---

## 🌟 Key Features

### 🎓 For Students
- **Smart Event Discovery**: Search and multi-filter across 8 categories (Workshops, Hackathons, Seminars, Coding Competitions, Cultural Events, Sports, Placement Training, Club Activities).
- **Personalized AI Recommendations**: Dynamic synergy matching based on student skills, department, and past attendance history.
- **Dynamic Interest Tuner**: Adjust skills in real-time and watch AI recommendations recalculate live.
- **Digital QR Event Passes**: Instant mobile access tickets with unique codes, pass download, and printable views.
- **Student Wallet ("My Events")**: Manage registered, upcoming, and completed events, with 1-click registration cancellation and verified Certificate of Participation downloads.

### 🏛️ For Administrators
- **Admin Intelligence Dashboard**: Real-time analytics tracking participation rates, category distribution, and monthly registration growth.
- **AI Turnout Forecasts**: Predictive turnout velocity models to avoid venue overcrowding.
- **Event Lifecycle Management**: Full CRUD controls to create, edit, and delete events.
- **AI Agenda Generator**: One-click AI assistant that auto-generates professional event copy, rules, and schedules.
- **Participant Roster & Check-In**: View registered attendees, search by ID, toggle attendance, and export attendee CSV rosters.

---

## 🚀 Tech Stack

- **Frontend**: React 18 + Vite
- **Styling**: Tailwind CSS (College-tech blue & purple palette, glassmorphism)
- **Icons**: Lucide React
- **Animations & Effects**: Canvas Confetti, Tailwind CSS keyframes
- **State & Storage**: React Context + Browser LocalStorage persistence

## 🛠️ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
